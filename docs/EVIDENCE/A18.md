## Lock overlay revalidation (2026-10-23)

The desktop inactivity timer and Lock Screen menu display a local passphrase
overlay. The kernel GUI loop does not consume `Desktop::take_events()`, and the
overlay uses in-memory UI state rather than the KMS passphrase. Consequently,
this visual overlay does not lock the mounted vault or scrub KMS keys. The UI
now states this limitation on both the overlay and its Settings pane, and its
event comments no longer promise kernel duress handling. The UI honesty guard
failed first on the missing disclosure, then passed with 26 checks; `cargo test
-p kash-ui` passed. Kernel-backed user authentication, storage locking and
duress actions remain unimplemented.
