## 1. Specification & Requirements
1. Modern USB xHCI Controller Driver in `kernel/src/arch/x86_64/input.rs`:
   - Memory-mapped I/O initialization of capability registers: `CAPLENGTH`, `HCIVERSION`, `HCSPARAMS1` (MaxSlots, MaxPorts), `HCCPARAMS1` (64-bit context, Extended Capabilities).
   - Host Controller Reset sequence: stops running controller, pulses `USBCMD.HCRST`, awaits clearing of `HCRST` and `USBSTS.CNR`.
   - Device slot configuration (`CONFIG.MaxSlotsEn`).
   - Root hub port power management (`PORTSC.PP`) and live device connection detection (`PORTSC.CCS`), mapping port speed (Full, Low, High, SuperSpeed).
   - Starts host controller (`USBCMD.RS` and `USBCMD.INTE`).
   - Reports xHCI runtime state dynamically to `status::StatusRegistry::xhci_usb`.
2. Hardware USB HID decoders in `khal/src/xhci.rs`:
   - 8-byte standard USB boot keyboard reports: decodes modifier bits and HID keycodes to `KeyCode` and `InputEvent::KeyDown`.
   - 3-byte / 4-byte standard USB boot mouse reports: tracks button edge transitions to generate `MouseButtonDown` and `MouseButtonUp`, translates relative X/Y motion to `MouseMove`, and parses scroll wheel deltas to `MouseWheel`.
3. USB Mass Storage Class (BOT / SCSI) in `kblock/src/usb_msc.rs`:
   - Command Block Wrapper (CBW) 31-byte serialization and parsing (`USBC` magic `0x43425355`).
   - Command Status Wrapper (CSW) 13-byte serialization and parsing (`USBS` magic `0x53425355`).
   - Abstract `UsbBulkTransport` trait supporting bulk-in/bulk-out endpoints.
   - SCSI Command Descriptor Blocks for INQUIRY, READ CAPACITY (10), READ (10), WRITE (10), and SYNCHRONIZE CACHE (10).
