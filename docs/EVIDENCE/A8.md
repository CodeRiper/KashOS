## Summary of Changes
1. **`knet/src/tls.rs`**:
   - Implemented RFC 8446 compliant TLS 1.3 record header framing (`TlsRecordHeader`, `TlsContentType`, `TlsHandshakeType`).
   - Implemented `build_tls13_client_hello`: legacy_version 0x0303 compatibility, client random, session ID, cipher suites (`TLS_AES_128_GCM_SHA256`, `TLS_AES_256_GCM_SHA384`, `TLS_CHACHA20_POLY1305_SHA256`), and extensions (Server Name Indication / SNI, Supported Versions 0x0304, Supported Groups X25519, Signature Algorithms, Key Share).
   - Implemented `wrap_tls_application_data` and `unwrap_tls_application_data` for standard TLS record transport.
   - Implemented zero-allocation URL parsing (`parse_url`), HTTP/1.1 request formatting (`build_http_get_request`), and response parsing (`parse_http_response`).
2. **`knet/src/lib.rs` & `knet/tests/net_tests.rs`**:
   - Exported `tls` module.
   - Added unit tests: `test_tls13_client_hello_builder_and_record_header`, `test_tls_application_data_record_wrapping`, and `test_url_parser_and_http_request_response`.
3. **`kernel/src/net.rs`**:
   - Replaced placeholder HTTP client with real `http_get` implementation invoking URL parsing, kill switch enforcement, egress domain filtering via `FilterTable::evaluate`, and `smoltcp` TCP socket dispatch with TLS 1.3 ClientHello framing.
4. **`kernel/src/browser.rs`**:
   - Updated browser network banner to reflect active TLS 1.3 HTTPS client and smoltcp network stack.
