## Summary of Changes
1. **`kernel/src/vfs.rs`**:
   - `mount_root()`: Removed automatic format on open failure. Any failure logs `Failed to open kvault root volume: {:?}. Refusing automatic format to protect data.` and fails closed returning `Err(VfsError::CorruptFilesystem)`.
   - `format_root()`: Implemented explicit formatting method and public free function `pub fn format_root(master_key: &[u8]) -> Result<(), VfsError>`. Format can only be triggered explicitly by an administrator or the OS installer.
2. **`kvault/tests/vault_tests.rs`**:
   - Added `open_failure_does_not_mutate_or_format_device` asserting that failed `Vault::open` calls do not mutate the underlying block device.
3. **`kernel/src/selftest.rs`**:
   - Test 25 (`test_kvault_root_mount_and_bitflip_tamper_gate`) explicitly invokes `format_root` only when verifying an unmounted pristine acceptance test disk image.
