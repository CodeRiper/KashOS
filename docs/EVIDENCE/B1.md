# B1 Evidence: Untyped Memory Model and Watermark Allocator

## Implemented

The `ksel4-core` crate implements untyped memory descriptors, aligned watermark allocation, batch retyping, child untyped regions, write-right checks, device-memory restrictions, and watermark reset during revocation.

## Test Evidence

Workspace test T47 (`test_sel4_untyped_watermark_allocator_and_batch_retype`) in `ksel4-core/tests/milestones.rs` exercises batch allocation, alignment, hierarchical sub-untypeds, rights enforcement, exhaustion handling, and watermark reset. `cargo test -p ksel4-core` passes this test.

## Scope

This is an executable Rust model. Formal verification is not implemented. Hardware behavior is outside the test scope.
