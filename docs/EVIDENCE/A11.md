## Features Implemented
1. **Multi-Core AP Bring-Up (INIT-SIPI-SIPI)**:
   - Implemented real hardware Application Processor (AP) bring-up in `kernel/src/arch/x86_64/smp.rs` (`boot_secondary_cores`).
   - Implemented 16-bit to 64-bit transition trampoline page at physical address `0x8000` (page frame `0x08`).
   - Trampoline sets up temporary GDT, transitions through Protected Mode (CR0.PE=1), enables PAE (CR4.PAE=1) and Long Mode (EFER.LME=1), loads kernel CR3, sets up per-core stack, and calls `ap_entry(cpu_id)`.
   - Sends INIT IPI, waits 10 ms, sends first SIPI, waits 200 µs, sends second SIPI, and polls AP status with timeout.
   - Conforms to Rule R19: on single-core systems (profile T0), gracefully handles unpopulated sockets without hanging.
2. **Local APIC Secondary Core Initialization**:
   - Implemented `apic::init_ap()` in `kernel/src/arch/x86_64/apic.rs`.
   - Configures SVR (Spurious Vector 0xFF with enable bit 8), TPR=0, and sets up calibrated periodic timer on secondary cores.
3. **Scheduler Core Affinity & Multi-Core Distribution**:
   - Added `cpu_affinity: u64` bitmask to `TaskControlBlock` in `kscheduler`.
   - Added `set_task_affinity` and `can_run_on_core` to allow task pinning across CPU cores.
   - Added unit test `task_cpu_affinity_filtering_and_pinning` verifying core pinning and task migration.
