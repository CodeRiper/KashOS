## Finding Addressed
- **Task A7**: Provide real, tested hardware drivers for the three core network interface families supported by KashOS across vintage PCs, modern hardware, and hypervisors:
  1. **Intel e1000 (82540EM / 82545GB / 82574L)**: Circular TX & RX DMA descriptor rings, link status monitoring via `E1000_REG_STATUS`.
  2. **VirtIO-Net (`0x1AF4:0x1000` / `0x1041`)**: Paravirtualized split virtqueue network adapter with 10-byte `VirtioNetHdr` framing, RX/TX virtqueues, and queue notification.
  3. **Realtek RTL-8139 Fast Ethernet (`0x10EC:0x8139`)**: Continuous 8 KiB + 16 byte + 1500 byte wrap receive ring buffer, 4-descriptor transmit queue rotation via `TSAD`/`TSD` registers, `CAPR`/`CBR` offset synchronization, and link state readout via `MSR`.

## Summary of Changes
1. **`knet/src/lib.rs` & `knet/tests/net_tests.rs`**:
   - Added `Rtl8139PacketHeader` safe framing parser and validator (`parse`, `is_ok`, `packet_data_len`).
   - Added `VirtioNetHdr` serialization and deserialization (`to_bytes`, `from_bytes`).
   - Added unit tests for RTL8139 and VirtIO-Net header integrity and CRC offsets.
2. **`kernel/src/arch/x86_64/nic.rs`**:
   - Implemented real `VirtioNetDevice` split virtqueues: 8 RX descriptors, 8 TX descriptors, Available/Used rings, `transmit_frame`, and `receive_frame`.
   - Implemented real `Rtl8139Device`: 8192+wrap ring buffer, 4 TX descriptors with `TSAD`/`TSD` port I/O, `CAPR` update, `receive_frame`, and `is_link_up`.
   - Added `is_link_up` method across `E1000Device`, `VirtioNetDevice`, and `Rtl8139Device`.
   - Updated `NetworkDriverSubsystem`: unified dispatch in `transmit` and `receive` across all probed NICs, link state querying, and active driver reporting.
3. **`kernel/src/status.rs`**:
   - Added `nic_rtl8139: ComponentStatus` to `StatusRegistry` and manifest table.
4. **`kernel/src/shell.rs` & `kernel/src/kash.rs`**:
   - Integrated RTL8139 into `dmesg`, `kash` boot splash, and driver tier maps.
