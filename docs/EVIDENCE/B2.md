# B2 Evidence: CNode Guarded Radix Trees & Capability Derivation Tree (CDT)

## Date
2026-10-20

## What was implemented

### 1. Guarded Radix CSpace Address Resolution (`resolve_cptr`)
- Full seL4 Reference Manual §3.2 CSpace resolution algorithm.
- Multi-level CNode traversal consuming guard bits then radix bits from the CPtr.
- Guard mismatch detection and depth validation.
- Loop bounded by depth ≤ 64 with strictly increasing bits_consumed to prevent infinite loops.

### 2. CNode Operations (seL4 Reference Manual §3.3)

| Operation | Method | Description |
|---|---|---|
| CNode_Copy | `cnode_copy()` | Copy cap with rights attenuation; CDT child insertion; Untyped copy prohibited |
| CNode_Move | `cnode_move()` | Move cap to new slot; children re-parented; siblings updated |
| CNode_Mutate | `cnode_mutate()` | Atomic Move + rights intersection |
| CNode_Rotate | `cnode_rotate()` | 3-way atomic rotation: src→pivot, pivot→dest; all CDT links updated |
| CNode_Delete | `cnode_delete()` | Remove cap; children adopted by grandparent; Untyped-with-children rejected |
| CNode_SaveCaller | `cnode_save_caller()` | Mint one-shot Reply cap from caller TCB |
| CNode_SetGuard | `cnode_set_guard()` | Reconfigure guard value and size on CNode cap |

### 3. CDT Integrity Invariant Checker (`check_cdt_invariants`)
Verifies 5 structural invariants at runtime:
- **I1**: Null slots have no CDT links.
- **I2**: Sibling links are consistent (prev↔next bijection).
- **I3**: Every child's parent pointer matches the parent's child list; first_child has no prev_sibling.
- **I4**: Parent chain is acyclic (bounded by N hops).
- **I5**: Rights monotonicity — no child has more rights than its parent.
