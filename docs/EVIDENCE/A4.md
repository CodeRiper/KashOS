## Summary of Changes
1. **`kernel/src/arch/x86_64/mod.rs`**:
   - Mapped TPM 2.0 TIS MMIO physical aperture `0xFED4_0000` (Localities 0..4, 20 KiB) in `enable_wx_paging`.
2. **`kernel/src/arch/x86_64/tpm.rs`**:
   - Replaced in-memory simulation with real hardware driver supporting TIS MMIO and CRB control area protocols.
   - Implemented TCG command transmission over hardware MMIO FIFO (`tis_execute_command`, `tis_request_locality`, `tis_release_locality`).
   - Implemented real hardware command builders: `TPM2_Startup`, `TPM2_PCR_Extend`, `TPM2_PCR_Read`, `TPM2_GetRandom`.
   - Replaced simulated `pcr_bank` with TCG PC Client Platform Firmware Profile standard `measurement_log` (CRTM event log).
   - Enforced honest component status reporting (`ComponentStatus::Real` when hardware is probed and responsive; `ComponentStatus::NotAvailable` when no physical chip is present).
