## Summary of Changes
1. **`kboot/src/lib.rs`**:
   - Defined TCG PC Client standard event log data structures: `TcgPcrEvent2` with `pcr_index`, `event_type`, SHA-256 `digest`, and `event_data`.
   - Added standard event classifications: `EV_S_CRTM_CONTENTS`, `EV_POST_CODE`, `EV_SEPARATOR`, `EV_ACTION`.
   - Defined platform security epoch constant `KASH_SECURITY_EPOCH = 2`.
2. **`kernel/src/arch/x86_64/tpm.rs`**:
   - Integrated event log recording into `measure_boot_stage`, logging every measured stage payload.
   - Added anti-rollback verification: `check_anti_rollback` and `ratify_anti_rollback` bound to TPM 2.0 NV monotonic counter.
   - Added interactive diagnostics: `print_pcr_report()`, `print_tcg_event_log()`, and `print_anti_rollback_status()`.
3. **`kernel/src/selftest.rs`**:
   - Updated Test 22 to assert that all 12+ boot stages are recorded in the TCG event log, and that monotonic security epoch rollback attempts are rejected.
4. **`kernel/src/shell.rs`**:
   - Added `tpm`, `measured-boot`, `tpm pcr`, `tpm eventlog`, and `tpm anti-rollback` commands to the interactive shell.
