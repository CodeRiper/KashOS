## 2. Implementation Summary
1. **FADT (Fixed ACPI Description Table) Parser (`kernel/src/arch/x86_64/acpi.rs`)**:
   - Locates FADT (`FACP`) table via RSDP -> XSDT/RSDT.
   - Parses critical hardware registers:
     - `SMI_CMD` port and `ACPI_ENABLE`/`ACPI_DISABLE` command bytes.
     - `PM1a_CNT_BLK` and `PM1b_CNT_BLK` I/O ports.
     - `RESET_REG` Generic Address Structure (System I/O vs System Memory) and `RESET_VALUE`.
     - `RESET_REG_SUP` flag detection (bit 10 of FADT flags).
     - 32-bit and 64-bit `X_DSDT` pointer resolution.
2. **AML Bytecode Scanner for Sleep State 5 (`\_S5`)**:
   - `parse_aml_s5`: Traverses DSDT AML bytecode to locate the `_S5` definition block (`Name(_S5, Package() { slp_typa, slp_typb, ... })`).
   - Decodes AML integers (`ZeroOp`, `OneOp`, `BytePrefix`, `WordPrefix`, `DWordPrefix`) to extract exact hardware `SLP_TYPa` and `SLP_TYPb` values.
3. **Deterministic Hardware Poweroff (`poweroff`)**:
   - Enables ACPI hardware mode if not already active via `SMI_CMD` and verifies `SCI_EN` assertion.
   - Calculates sleep control words `(SLP_TYPa << 10) | (1 << 13)` (`SLP_EN`) and writes to `PM1a_CNT_BLK` and `PM1b_CNT_BLK`.
   - Multi-tier hypervisor and emulator fallback chain (QEMU/Bochs port `0x604` / `0xB004`, VirtualBox port `0x4004`, and triple fault).
4. **Deterministic Platform Reset (`reboot`)**:
   - ACPI Reset Register write (`RESET_VALUE` to `RESET_REG` I/O port or MMIO).
   - PCI Reset Control register (port `0xCF9` pulse `0x02` then `0x06`).
   - PS/2 8042 Keyboard Controller reset pulse (`0xFE` to port `0x64`).
   - Fast A20 Reset (port `0x92` bit 0 pulse).
   - Failsafe triple fault.
5. **System Integration**:
   - `reboot()` exposed through `crate::arch` across `x86_64` and `aarch64`.
   - Shell `reboot` command connected directly to clean amnesic scrub and hardware platform reboot.
