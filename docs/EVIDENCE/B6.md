## Date

## Summary of Accomplishment

Milestone B6 implements seL4-compliant Thread Control Blocks (`TcbObject`), comprehensive lifecycle state transitions, architecture-specific register contexts (`UserContext`), Maximum Controlled Priority (MCP) hierarchical authority bounds, bound notification signaling, and kernel-to-user fault IPC delivery.

### Key Architectural Implementations

1. **Thread Lifecycle State Machine (`ThreadState`)**
   - **`Inactive`**: Newly minted TCB. Cannot be scheduled until configured with CSpace, VSpace, and fault endpoint.
   - **`Ready`**: Thread is runnable and eligible for scheduling.
   - **`BlockedOnReceive` / `BlockedOnSend` / `BlockedOnNotification`**: Thread is blocked on a microkernel synchronization primitive.
   - **`Suspended`**: Thread execution is halted by `seL4_TCB_Suspend` or an unhandled hardware/software fault.
   - **`Restart`**: Instruction pointer rewound to restart the faulting instruction after fault resolution.

2. **Thread Configuration (`tcb_configure` / `seL4_TCB_Configure`)**
   - Configures the four fundamental capability associations:
     - `fault_ep`: Capability to an Endpoint where thread faults are routed.
     - `cspace_root`: Capability to the CNode at the root of the thread's guarded radix tree.
     - `vspace_root`: Capability to the VSpace root (PML4 page directory).
     - `ipc_buffer_vaddr`: User virtual address for out-of-band IPC messages and capability transfers.
   - Automatically transitions an `Inactive` thread to `Ready`.

3. **Register Context Management (`tcb_read_registers` / `tcb_write_registers`)**
   - Architecture-specific register capture (`UserContext` on x86_64: `rip`, `rsp`, `rflags`, `rax`, `rbx`, `rcx`, `rdx`, `rsi`, `rdi`, `rbp`, `r8`..`r15`).
   - Strict capability rights gating:
     - `READ` right required to read thread registers (`seL4_TCB_ReadRegisters`).
     - `WRITE` right required to write thread registers (`seL4_TCB_WriteRegisters`).

4. **Maximum Controlled Priority (MCP) Authority Bounds**
   - Implements seL4 priority ceiling security: a thread $A$ managing thread $B$ cannot elevate $B$'s priority or MCP higher than $A$'s own MCP.
   - `tcb_set_priority(target, auth, prio)`: Rejects with `SeL4Error::InsufficientRights` if `prio > auth.mcp`.
   - `tcb_set_mc_priority(target, auth, mcp)`: Rejects with `SeL4Error::InsufficientRights` if `mcp > auth.mcp`.

5. **Bound Notification Association (`tcb_bind_notification` / `tcb_unbind_notification`)**
   - Associates an asynchronous Notification object with a TCB (`seL4_TCB_BindNotification`).
   - Enables unified wait semantics: an active thread can wait on an endpoint and receive bound notification signals seamlessly.

6. **Fault Delivery Architecture (`tcb_deliver_fault`)**
   - Translates hardware exceptions (Page Fault, General Protection Fault, Invalid Opcode, Divide Error) into standard seL4 fault IPC messages.
   - Message packing format:
     - `MessageInfo.label = FaultType`
     - `registers[0] = fault_addr`
     - `registers[1] = fault_code`
     - `registers[2] = ip`
   - Automatically suspends the faulting thread pending supervisor reply.
   - Delivers the IPC message directly to the registered fault handler endpoint.
