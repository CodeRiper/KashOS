## Summary of Changes
1. **`khal/src/vtd.rs` & `khal/src/lib.rs`**:
   - Implemented ACPI DMAR parser (`parse_dmar_bytes`): checks signature, length, checksum; extracts HAW, INTR_REMAP flags, DRHD structures (with segment, register base, flags, device scopes), and RMRR memory ranges.
   - Implemented standard VT-d bitfield structures (`VtdRootEntry`, `VtdContextEntry`, `SlptEntry`, `VtdFaultReason`, `VtdFaultRecord`).
   - Implemented real 4-level Second-Level Page Table (`SlptPageTable`): Level 4 (PML4) -> Level 3 (PDPT) -> Level 2 (PD) -> Level 1 (PT) with superpage (2 MiB) and permission enforcement (Read, Write, Snoop).
2. **`khal/tests/vtd_tests.rs`**:
   - Validated ACPI DMAR parsing on valid and corrupt test vectors.
   - Tested 4-level SLPT DMA translation, permission enforcement (Read-Only write traps, Write-Only read traps), unmapped address traps, and unbound device isolation.
3. **`kernel/src/arch/x86_64/vtd.rs`**:
   - Replaced fake 32-entry array and hardcoded `0x2000_0000` with real `SlptPageTable`.
   - Updated `init()`: reads ACPI DMAR physical memory, parses DRHD entries, programs hardware units, and sets `s.vtd_iommu = Real` ONLY if an active hardware unit is confirmed.
   - In `init_hardware()`: never sets `is_enabled = true` unless verified by hardware `VTD_GSTS_TES` bit.
4. **`kernel/src/selftest.rs`**:
   - Updated status assignment: `s.vtd_iommu` is updated strictly based on `get_iommu_status()` (resolving Finding F9).
