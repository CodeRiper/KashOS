## Summary of Changes
1. **`kvault/src/crypto.rs` & `kvault/src/lib.rs`**:
   - Implemented `pub fn derive_key(passphrase: &[u8], salt: &[u8; 32], info: &[u8]) -> VaultResult<Key>` using HKDF-SHA256 with domain separation.
   - Added unit test `derive_key_is_deterministic_and_domain_separated` in `kvault/tests/vault_tests.rs`.
2. **`kernel/src/kms.rs`**:
   - Replaced random CSPRNG key generation at boot with deterministic passphrase derivation via `kvault::derive_key`.
   - Implemented `unlock_with_passphrase(&mut self, passphrase: &[u8]) -> Result<(), KmsError>`.
   - Passphrase First, TPM Second: Sovereign master key is derived deterministically from the passphrase, and bound to TPM 2.0 PCR 4 (Kernel Code) & PCR 7 (Secure Boot Policy) when TPM hardware is present. When TPM is absent or unprovisioned (T0/T1 tier), system operates cleanly in Passphrase-Only mode.
   - Removed `"generating fresh master key"` from all runtime paths.
