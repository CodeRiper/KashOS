# Evidence: Task A6 — Real TCP/IP with smoltcp

## Status

Needs revalidation. Audit date: 2026-10-20. The previous “Completed / Verified”
status treated package-level model tests as a complete network path.

## Source findings

- `knet::SmolNetStack` and `RingDevice` exist, but their rings are in-memory
  queues. The kernel did not connect the adapter to `arch::nic_receive` /
  `arch::nic_transmit`, and no kernel call site drove its polling loop.
- The old kernel service used a separate `TcpIpStack` with fixed private IPv4,
  gateway, and netmask values. Its handshake calls only advanced a local socket
  state model; they did not exchange peer packets. The table now marks these
  rows as model state and the address is unconfigured.
- The old ingress wrapper returned raw NIC frames without running them through
  the network policy. Kernel ingress is now unavailable until a filtered path
  exists.
- Kernel TCP connect/send/receive and DHCP status no longer report successful
  service behavior. TCP/DHCP/stack polling are unavailable until the NIC path is
  connected.
- Kernel egress and ping do not transmit frames. Egress always returns the
  killswitch-blocked result; HTTP(S), DNS protocol lookup, and anonymity routing
  remain unavailable. Literal IPv4 parsing is not DNS resolution.

## Regression coverage

`tools/test_network_fail_closed.py` runs in the existing CI honesty gate. The
follow-up checks enforce private kernel network state, disabled TCP/DHCP/ingress,
no physical NIC call from the kernel egress method, and model-only socket labels.
`knet/tests/net_tests.rs` exercises smoltcp against its test ring; it does not
establish a NIC, DHCP lease, DNS query, remote TCP handshake, filter integration,
or real packet egress.

## Verification

- `python tools/test_network_fail_closed.py`
- `python tools/claims_lint.py`
- `cargo test -p knet`
- `cargo check --release --manifest-path kernel/Cargo.toml --target x86_64-unknown-none`
- QEMU boot smoke test confirms boot remains available with remote traffic disabled.

A6 remains incomplete. No live network test is claimed. The next implementation
must connect a supported NIC to the smoltcp device, filter ingress and egress,
and pass packet-level QEMU tests before enabling any remote transport.
