1. **`knet/Cargo.toml`**:
   - Enabled `smoltcp` 0.14 with core `#![no_std]` features: `alloc`, `proto-ipv4`, `proto-dhcpv4`, `proto-dns`, `socket-tcp`, `socket-udp`, `socket-icmp`, `socket-dhcpv4`, `socket-dns`, `medium-ethernet`.
2. **`knet/src/lib.rs`**:
   - Implemented `smoltcp::phy::Device` for `RingDevice<'a>` utilizing zero-copy `RingRxToken` and `RingTxToken`.
   - Implemented `SmolNetStack` orchestrating `smoltcp::iface::Interface`, `SocketSet`, DHCPv4 client, DNS resolution, and TCP connection lifecycle.
3. **`kernel/src/net.rs`**:
   - Integrated `SmolNetStack` into kernel `NetworkService`. Added `dhcp_status()`, `tcp_connect()`, `tcp_send()`, `tcp_recv()`, and `resolve()` dispatchers.
4. **`knet/tests/net_tests.rs`**:
   - Added `smol_net_stack_device_and_socket_test` validating real device polling, interface configuration, and TCP socket lifecycle.
