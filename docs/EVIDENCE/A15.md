## 1. Implementation Overview
In `kblock/src/ahci.rs`, `kblock/src/nvme.rs`, `kernel/src/arch/x86_64/pci.rs`, `kernel/src/blockdev.rs`, and `kernel/src/kash.rs`:
1. **Hardened SATA AHCI Controller Driver (`AhciController`)**:
   - Structured `HbaCmdTable` (128-byte aligned) containing CFIS (64 bytes), ACMD (16 bytes), reserved pad (48 bytes), and PRDT entries at offset 0x80.
   - Populated PRDT entries with physical base address (`dba`/`dbau`), transfer byte count (`dbc`), and interrupt completion flags for both `READ DMA EXT` (0x25) and `WRITE DMA EXT` (0x35).
   - Real hardware cache flush implementation sending `ATA_CMD_FLUSH_EXT` (0xEA) with completion tracking and error status check on `port.tfd`.
   - Cleared pending interrupts and error flags (`port.is`, `port.serr`) prior to command submission.
2. **NVMe PCIe Controller Driver (`NvmeController`)**:
   - Implemented NVMe 1.4 register offsets and bitmasks: `CAP`, `VS`, `CC`, `CSTS`, `AQA`, `ASQ`, `ACQ`, and dynamic doorbell strides.
   - Implemented `NvmeQueue` managing circular Submission Queues (64-byte SQE) and Completion Queues (16-byte CQE) with phase bit inversion on ring wrap-around.
   - Implemented full controller initialization sequence: controller reset via `CC.EN = 0`, queue pair allocation, `CC.EN = 1` enable handshake, and Admin commands `Create I/O CQ` (0x05) and `Create I/O SQ` (0x01).
   - Implemented `PersistentBlockDriver` trait for `NvmeController`: `read_sectors` (0x02), `write_sectors` (0x01), and `flush_cache` (0x00).
3. **PCI Enumeration & Subsystem Binding**:
   - Added `find_nvme()` in `kernel/src/arch/x86_64/pci.rs` matching PCI class 0x01, subclass 0x08.
   - Updated block storage probe order in `kernel/src/blockdev.rs`: NVMe SSD -> SATA AHCI -> VirtIO-Block -> Legacy PATA/IDE -> Volatile RAM.
   - Bound active driver detection into `kernel/src/kash.rs` `DriverMap` to accurately reflect `native sDDF` when hardware storage is present.
