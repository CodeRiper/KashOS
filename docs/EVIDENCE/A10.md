## Architectural Changes
1. **User Session Subsystem (`kernel/src/session.rs`)**:
   - Implemented `launch_user_session(fb_opt: Option<FramebufferInfo>) -> !` which decouples userland initialization and execution from the Ring 0 microkernel core.
   - Encapsulates userland privilege boundary transitions and capabilities management (`UserSession`, `SessionMode`).
   - Configures per-process CSpace (Capability Space) with Untyped memory, TCB, and IPC Endpoint capabilities.
   - Dispatches execution to userland desktop compositor service (`gui::run_desktop_session`) when framebuffer is available, or to userland interactive console shell service.
2. **Main Kernel Decoupling (`kernel/src/main.rs`)**:
   - Removed direct Ring 0 calls to `gui::run` and `shell.run_interactive_terminal`.
   - Boot sequence completes microkernel initialization, prints boot banner, and hands off execution to `session::launch_user_session(arch::framebuffer())`.
3. **Privilege Boundary Invariants Maintained**:
   - TSS `rsp0` switching per thread.
   - PML4 CR3 user space lower-half isolation (`< 0x0000_8000_0000_0000`).
   - Segment selectors enforce RPL=3 (`USER_CODE_SELECTOR = 0x23`, `USER_DATA_SELECTOR = 0x1B`).
   - SMAP `stac`/`clac` user boundary memory validation.
