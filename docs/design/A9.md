# Design: Task A9 — Real IOMMU (Intel VT-d)

> Revalidation on 2026-10-20 found that the implementation below did not program
> hardware-visible translation tables or ACS controls. This remains a target
> design, not current support. VT-d and ACS now fail closed; see
> [`../EVIDENCE/A9.md`](../EVIDENCE/A9.md).

## Finding Reference
- **Finding F8 (Severity S1)**: The VT-d "DMA check" is a software table (32 entries). The context table address is the made-up constant `0x2000_0000`. When no MMIO base is found it just sets `is_enabled = true`.
- **Finding F9 (Severity S1)**: Selftest unconditionally marks `s.vtd_iommu = Real` even when hardware is absent or simulated.

## Architecture & Requirements
1. **Real ACPI DMAR Parsing**:
   - Parse ACPI DMAR (DMA Remapping Reporting) header: Host Address Width (HAW), Flags.
   - Iterate DMAR remapping structures:
     - Type 0: DRHD (DMA Remapping Hardware Unit Definition):
       - Parse Flags (`INCLUDE_PCI_ALL` bit 0).
       - Parse PCI Segment.
       - Parse 64-bit Register Base Address (MMIO base).
       - Parse Device Scope entries (Scope Type, Length, Bus, Dev, Func path).
     - Type 1: RMRR (Reserved Memory Region Reporting):
       - Parse Base Address, Limit Address, Device Scopes.
2. **Real Intel VT-d Hardware Unit Initialization**:
   - If MMIO base is non-zero, map registers:
     - Read `VERSION`, `CAP`, `EXT_CAP`.
     - Allocate 4 KiB Root Table aligned to 4096 bytes.
     - Write `RTADDR` register and issue `VTD_GCMD_SRTP` (Set Root Table Pointer), await `VTD_GSTS_RTPS`.
     - Invalidate Context Cache (`CCMD`) and IOTLB.
     - Issue `VTD_GCMD_TE` (Translation Enable), await `VTD_GSTS_TES`.
     - Set `is_enabled = true` ONLY if hardware confirmed `TES`.
   - If no MMIO base or hardware unavailable:
     - `is_enabled = false`, status is `NotAvailable`. Never simulate!
3. **Real Second-Level Page Table (SLPT) Hierarchy**:
   - Replace the 32-entry flat array with a real 4-level SLPT:
     - Root Table (256 entries for buses 0..255).
     - Context Table (256 entries for dev/func 0..255).
     - Second-Level Paging (PML4 -> PDPT -> PD -> PT, or 2 MiB superpages).
   - `map_device_dma`:
     - Creates intermediate SLPT paging levels as needed.
     - Sets leaf SLPTE with Read, Write, and Snoop bits.
   - `unmap_device_dma`:
     - Clears the SLPTE leaf.
   - `translate_dma`:
     - Walks the real Root Table -> Context Table -> SLPT page table.
     - Rejects unauthorized access with precise `VtdFaultReason` (RootEntryNotPresent, ContextEntryNotPresent, TranslationNotPresent, WritePermissionViolation, ReadPermissionViolation).
     - Updates fault registers and records fault in `last_fault`.
4. **Honest Status Reporting (Rule R1, R2, Finding F9)**:
   - `vtd_iommu` in `StatusRegistry` is `Real` if and only if an ACPI DMAR table was discovered and hardware units were probed.
   - Selftest never overwrites status with fake `Real`.
