## 1. Objectives & Architectural Specification
In the KashOS Master Engineering Plan, Finding F18 requires that all items identified in `CRITIQUE_AND_VERIFICATION_REPORT.md` (Items 1.1–1.6, 2.1–2.13) must be systematically re-verified with empirical programmatic evidence rather than static textual claims. Task A20 establishes a verification and hardening gate:

1. **Unveil Prefix Matching & Path Traversal Confinement (Critique 2.10)**:
   - Path normalization must resolve `.` and `..` components cleanly to prevent directory traversal escapes (e.g., `/vault/../etc/shadow` -> `/etc/shadow`).
   - Unveil matching must enforce strict delimiter boundaries (`/` boundary or exact equality) so that granting access to `/vault` does not implicitly grant access to `/vault_leak`, `/vaultbreaker`, or `/vault_exfil`.
   - Unveil entry count must be bounded (`<= 64`) to prevent kernel resource exhaustion (`E2BIG`).

2. **Per-Process Sandbox Isolation (Critique 2.10)**:
   - Sandboxes must not be global. Each active thread/process must have an isolated sandbox record indexed by PID (`ProcessSandboxTable`).
   - Unveils or pledge restrictions executed in Process A must never affect Process B.

3. **Memory Amnesic Zeroing on Revocation (Critique 2.9)**:
   - Revoking a capability via the capability derivation tree (`kcore::space` / `cap::sel4_cnode_revoke`) must not only invalidate capability slot descriptors, but must explicitly scrub the underlying physical frame memory to zero, preventing residual data leakage across task boundaries.

4. **Hardware Entropy Fail-Closed Policy (Critique 1.5)**:
   - Hardware entropy initialization (`arch::hw_entropy`) must fail closed: if hardware entropy sources (RDRAND/RDSEED) are unavailable or fail health checks, system initialization halts or signals an error rather than silently proceeding with zeroed buffers.

5. **Syscall ABI Hardening & Speculation Mitigations (Critiques 2.1–2.4, 2.11)**:
   - Syscall entrypoint enforces `swapgs`, switches to a dedicated 16 KiB kernel stack, corrects argument 5 register ordering, and maintains 16-byte stack alignment.
   - Speculation mitigations (`IA32_SPEC_CTRL`) must verify CPUID leaf 7 EDX feature flags before writing MSRs to avoid `#GP` exceptions.

6. **Automated Acceptance Gate (Test 45)**:
   - Integrate `test_audit_reverification_and_hardening_gate()` as Test 45 in `kernel/src/selftest.rs` within `run_hardening_verification_tests()`.
   - Verify every condition at boot and during self-test runs.
