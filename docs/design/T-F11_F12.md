# Design Note: T-F11_F12 (ISO Manifest Cleanup & Placeholder Security Removal)

**Task ID**: T-F11_F12  
**Date**: 2026-10-18  
**Author**: Builder Agent  
**Guide Reference**: KashOS Build Guide v2, Section 5 (F-11, F-12), Findings V-10 & V-11  

---

## 1. Objective
Purge placeholder security tokens and false manifest claims:
1. In `scripts/make_iso.py`:
   - Delete placeholder string `manifest.sig` (`b"ED25519:KASH_KERNEL_AUTHENTIC_BUILD_SIGNATURE_OK_2026_PQ_VERIFIED"`).
   - Remove decorative unparsed files (`etc/security.conf`) and empty `.kapp` manifest stubs that reference non-existent binaries (`editor.elf`, `solver.elf`, `main.py`, `payroll.jar`, `browser.elf`).
   - Cleanse `manifest.toml`: remove unbacked claims (`XTS-AES-256`, `high_assurance_graphene_hardened`), synchronize version to `0.1.0`.
2. In `kernel/src/kapp.rs`:
   - Remove hard-coded mock application bundles that reference non-existent binaries.
   - For any launch request without a verified ELF binary on disk, report honest status `NotAvailable("Application runtime binaries require Phase U userland build")`.
3. In `kernel/src/shell.rs`:
   - Remove false signature validation success prints (`✓ Ed25519 signature VALID`) and simulated capsule execution prints.

---

## 2. Approach & Implementation Steps

### A. Cleansing `scripts/make_iso.py`
- Read version directly from root `VERSION` file.
- Manifest specifies only real active features:
  ```toml
  [system]
  os_name = "KashOS"
  version = "0.1.0"
  architecture = "x86_64"
  security_profile = "capability_microkernel"

  [storage]
  vault_filesystem = "kvault-fs"
  encryption = "Argon2id + XChaCha20-Poly1305"
  blinded_superblocks = true
  ```
- Omit `manifest.sig` until real offline signing tool `tools/ksign` is implemented in Phase 5.
- Omit placeholder `/kapps` directories until Phase U builds real ELF user binaries.

### B. Cleansing `kernel/src/kapp.rs` & `kernel/src/shell.rs`
- Report `StatusRegistry` or return explicit error: `Err("No user-mode ELF binary available (deferred to Phase U)")`.
- Remove deceptive checkmark prints.

---

## 3. Risks & Mitigations
- **Risk**: Existing tests or scripts might look for `/manifest.toml`.
- **Mitigation**: `/manifest.toml` remains in the ISO with honest, accurate metadata matching what is implemented.

---

## 4. Still False / Partial / Not Done Afterwards
- Real Ed25519 offline signing with detached signature verification in `kboot` will be fully realized in Phase 5.
- User binaries (`.kapp` ELFs) will be compiled from real C/Rust code in Phase U.
