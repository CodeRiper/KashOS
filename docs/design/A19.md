## 1. Objectives & Architectural Specification
To allow standard user-space software, security tooling, and Rust applications to execute seamlessly on KashOS without modifying their source code, KashOS requires a comprehensive user-space runtime and POSIX compatibility substrate:

1. **`kash-rt` (KashOS Userland Runtime Crate)**:
   - Provide an autonomous `#![no_std]` runtime crate located at `kash-rt/` in the workspace root.
   - Support both native x86_64 fast system calls (`syscall` / `sysretq`) and AArch64 Supervisor Calls (`svc #0`).
   - Deliver CRT0 process startup routines (`_start`) that parse the initial user stack frame (`argc`, `argv`, `envp`), initialize the heap allocator, execute `main()`, and flush streams before invoking `exit()`.

2. **POSIX C-ABI Compatibility & System Call Substrate**:
   - File Operations: `read`, `write`, `open`, `close`, `lseek`, `stat`, `fstat`, `access`, `ioctl`.
   - Virtual Memory: `brk`, `mmap`, `munmap`, `mprotect` adhering to the kernel W^X security invariants.
   - Process & Time: `exit`, `getpid`, `getppid`, `sched_yield`, `nanosleep`, `clock_gettime`, `gettimeofday`.
   - Security Confinement: OpenBSD-style `pledge()` and `unveil()` runtime hooks to enforce least-privilege sandboxing from user space.

3. **User-Space Memory Allocator (`malloc`, `free`, `realloc`, `calloc`)**:
   - Boundary-tag free list / segregated heap allocator operating over `brk` and anonymous `mmap`.
   - Canary word verification at chunk boundaries to prevent and detect heap metadata corruption and buffer overflows.
   - Implement Rust's `core::alloc::GlobalAlloc` (`KashUserAllocator`) enabling user-space Rust binaries to leverage `alloc::vec::Vec`, `alloc::string::String`, and `alloc::boxed::Box`.

4. **Standard C String & Memory Manipulation Utilities**:
   - High-assurance implementations of `strlen`, `strnlen`, `strcmp`, `strncmp`, `strcpy`, `strncpy`, `strcat`, `strchr`.
   - Memory manipulation: `memcpy`, `memmove`, `memset`, `memcmp`, `memchr`.

5. **`relibc` Adaptation Layer**:
   - Interface definitions matching `relibc::platform::sys` to enable drop-in replacement of C standard library functionality.
   - POSIX errno translation and structure mapping (`Stat`, `TimeSpec`, `TimeVal`, `UtsName`).
