## 1. Objectives & Specification
1. Implement xHCI (Extensible Host Controller Interface 1.0/1.1) PCI discovery, capability and operational register memory-mapped I/O initialization:
   - Read `CAPLENGTH`, `HCIVERSION`, `HCSPARAMS1` (MaxSlots, MaxPorts), `HCCPARAMS1` (64-bit context, Extended Capabilities xECP).
   - Perform BIOS-to-OS ownership handoff via `USBLEGSUP` extended capability register.
   - Execute host controller reset sequence (`USBCMD.HCRST` -> `USBSTS.CNR == 0`).
   - Initialize Device Context Base Address Array Pointer (`DCBAAP`), Command Ring (`CRCR`), and Event Ring Segment Table (`ERST`).
   - Enable controller run state (`USBCMD.RS = 1`, `USBCMD.INTE = 1`).
2. Implement root hub port scanning & power management (`PORTSC[1..MaxPorts]`):
   - Power on root hub ports (`PORTSC.PP = 1`).
   - Detect device connection (`PORTSC.CCS == 1`) and determine link speed (Low, Full, High, SuperSpeed).
3. Implement USB HID report decoders:
   - 8-byte standard USB boot keyboard reports (modifiers, keycodes, translation to `InputEvent::KeyDown`).
   - 4-byte standard USB boot mouse reports (buttons, delta X, delta Y, scroll wheel).
4. Implement USB Mass Storage Class (BOT / SCSI) transport:
   - Command Block Wrapper (CBW) and Command Status Wrapper (CSW) transaction dispatch in `kblock/src/usb_msc.rs`.
   - Wire `UsbMassStorageDevice` into `kblock` persistent storage subsystem.
5. Update `status.rs`:
   - Set `xhci_usb` to `ComponentStatus::Real` when xHCI controller is initialized, or `ComponentStatus::NotAvailable` on legacy T0 machines where only PS/2 / UHCI is present.
