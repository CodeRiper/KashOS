# Design Note: Task A10 — User-Space Services & Ring 3 Transition

## Metadata
- **Task ID**: A10
- **Finding**: F10 (Severity S2) — Ring 3 ran only inside self-tests with hand-assembled machine code. The desktop (`gui::run`) and shell ran directly in Ring 0 from `kernel/src/main.rs`.
- **Date**: 2026-10-19
- **Author**: Akash <akash.official.j@gmail.com>

## 1. Objectives & Requirements
1. Eliminate Ring 0 invocation of the desktop UI (`gui::run`) and terminal shell from `kernel/src/main.rs`.
2. Implement a dedicated User Session subsystem (`kernel/src/session.rs`) that:
   - Encapsulates userland privilege boundary transitions.
   - Allocates isolated capability spaces (CSpaces) and page tables (CR3) for user-space tasks.
   - Spawns the root user session with RPL=3 segment selectors (`USER_CODE_SELECTOR = 0x23`, `USER_DATA_SELECTOR = 0x1B`).
   - Supports both graphical desktop sessions and interactive terminal shell sessions with fault containment.
3. Ensure the microkernel scheduler (`kscheduler`) dispatches and manages user-mode threads according to their QoS tier.
4. Pass all verification suites and confirm Finding F10 flips to ABSENT in `tools/verify_findings.py`.

## 3. Implementation Plan
1. Create `kernel/src/session.rs`:
   - `UserSessionMode`: Desktop(FramebufferInfo) vs Console.
   - `launch_user_session(fb_opt: Option<FramebufferInfo>) -> !`:
     Logs transition, initializes user-space session environment, registers initial user processes in the process table with CSpaces, and enters the preemptive scheduler / session dispatcher.
2. Update `kernel/src/main.rs`:
   - Replace lines 322–329 (`gui::run(fb)` and `shell.run_interactive_terminal()`) with `session::launch_user_session(arch::framebuffer())`.
   - Register `pub mod session;`.
3. Add unit and property tests verifying session initialization, user-mode selector sanity, and privilege boundaries.
4. Verify Finding F10 is ABSENT.
