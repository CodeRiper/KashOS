## 1. Context & Defect (Finding V-04)

In `kernel/src/csprng.rs`, when hardware CPU instructions (`RDRAND`/`RDSEED`) were missing (as on our T0 baseline machine: 2006 Core 2 Duo / Conroe CPU), the kernel previously logged:
```
[csprng] WARNING: Primary hardware entropy unavailable; using fallback timer mix
```
and proceeded to sample `rdtsc()` once, rotated it across a 32-byte seed buffer, and unconditionally logged:
```
[csprng] ✓ CSPRNG online (entropy pool verified with forward-secrecy re-keying)
```
On T0 hardware, cryptographic master vault keys generated from this pool were trivially guessable from boot timestamp deltas. This violated:
- **Rule 1**: Zero simulation, zero model code.
- **Rule 2**: Fail closed on missing hardware.
- **Rule 3**: No fake `[OK]`.
- **Rule 10**: Independent evidence.

## 2. Architecture & Approach

### 2.1 Multi-Source Entropy Harvester (`kernel/src/entropy.rs`)
Implement a multi-source entropy harvester capable of gathering true physical entropy across both legacy T0 systems and modern T2 systems:

1. **CPU Execution Jitter (HAVEGE / Jitter RNG algorithm)**:
   - Available on all x86_64 CPUs via `rdtsc`.
   - Executes non-trivial memory read/write iterations, cache line interactions, and branch variations.
   - Measures fine-grained cycle deltas: $\Delta_1 = t_1 - t_0$, $\Delta_2 = t_2 - t_1$, and second-order jitter $\delta = \Delta_2 - \Delta_1$.
   - **NIST SP 800-90B Online Health Tests**:
     - Repetition Count Test: detects stuck counters or hypervisors returning constant cycle counts.
     - Adaptive Proportion Test: verifies that delta values vary sufficiently.
   - Conservative entropy estimation: credits 0.5 bits per verified varying sample. 1024 verified samples yield 512 bits of conservative physical entropy. If variance tests fail, 0 bits are credited.

2. **Real-Time Clock (RTC) / CMOS**:
   - Reads CMOS registers `0x70`/`0x71` (seconds, minutes, hours, day, month, year).
   - Combined with sub-second TSC readings.
   - Conservative credit: 4 bits.

3. **Hardware CPU RNG (`RDSEED` / `RDRAND`)**:
   - Queried via `cpuid::detect()`.
   - On T1/T2 CPUs supporting `RDSEED`/`RDRAND`, samples 64-bit words via `hw_rand64()`.
   - Conservative credit: 64 bits per successful word.
   - On T0 CPUs (Conroe / Core 2 Duo), safely returns 0 without executing undefined opcodes.

4. **VirtIO-RNG (Paravirtualized Hardware RNG)**:
   - Probes for VirtIO-RNG PCI devices (`0x1af4:0x1005` or `0x1af4:0x1044`).
   - If present and configured, reads true entropy and credits 8 bits per byte.

5. **Hardware Interrupt Jitter**:
   - Intercepts IRQ 1 (PS/2 keyboard), IRQ 12 (PS/2 mouse), timer, and disk interrupts.
   - Samples low 32 bits of TSC on interrupt arrival.
   - Human interaction (keystroke/mouse) credits 1 bit per event.

6. **Persisted Random Seed**:
   - When persistent storage is mounted, mixes `/var/lib/random-seed` into the pool and rewrites 32 fresh bytes for subsequent boots.

### 2.2 Pool Conditioning & Mixing
- The entropy pool is conditioned using SHA-256 (`sha2` crate with `force-soft`).
- All inputs are tagged with domain separators (`b"source:cpu-jitter"`, `b"source:rtc"`, `b"source:rdrand"`, etc.) and monotonic counters before hashing.
- The 256-bit pool key is updated via HMAC/digest mixing.

### 2.3 Strict Fail-Closed Gate & Entropy Counter
- Maintains an atomic or spinlock-protected `entropy_bits: usize`.
- Any cryptographic key generation (`kms::init()`, `generate_master_key()`) must verify:
  ```rust
  if entropy::available_bits() < 256 {
      return Err(EntropyError::NotEnoughEntropy);
  }
  ```
- If entropy is insufficient (< 256 bits), key generation fails closed with an explicit error. It never silently falls back to an unseeded state.

### 2.4 Structured Serial Event
Upon successful initialization and seeding:
```json
KASH-EVT {"t":1234567,"src":"entropy","ev":"seeded","bits":512,"sources":["cpu-jitter","rtc"]}
```

## 3. Risks & Mitigations

- **Hypervisor invariant TSC**: In hypervisors where `rdtsc` returns deterministic ticks, the online repetition/adaptive proportion test rejects the jitter stream and refuses to credit bits.
- **Boot Performance**: 1024 jitter samples take < 2 milliseconds on a 1.8 GHz Core 2 CPU, ensuring fast boot times without hanging.

---

## 4. What Will Still Be False / Partial / Not Done Afterwards

1. **Bare-metal VirtIO-RNG**: On physical hardware without a hypervisor, VirtIO-RNG will report `NotAvailable`.
2. **Persisted Random Seed**: Until persistent storage (Phase 4 / Phase 6) is mounted, early boot relies entirely on hardware jitter, RTC, and CPU RNG.
3. **Formal Entropy Min-Entropy Bound Proofs**: Statistical entropy credits are conservative approximations based on NIST SP 800-90B heuristics; formal machine-checked proof of min-entropy is not done (deferred to `proofs/`).
