## 1. Objectives & Specification
1. **Double-Buffering & Dirty Rectangles Architecture (`kernel/src/display.rs`)**:
   - `Rect`: Geometry primitives `(x, y, width, height)` with intersection, union, and clamping.
   - `DirtyTracker`: Aggregates mutated sub-regions into bounding boxes to eliminate full-screen redrawing.
   - `DoubleBuffer`: Manages an off-screen RAM back-buffer (`Vec<u32>`) and copies only dirty bounding rects to the hardware front-buffer (linear framebuffer or VirtIO-GPU scanout) on `present()`, avoiding screen tearing and bus saturation.
2. **VirtIO-GPU 2D Driver (`kernel/src/arch/x86_64/virtio_gpu.rs`)**:
   - OASIS VirtIO 1.0 GPU specification support (PCI Vendor `0x1AF4`, Device ID `0x1050`).
   - Command Structures:
     - `VIRTIO_GPU_CMD_RESOURCE_CREATE_2D` (0x0101): Allocates host 2D resource with `B8G8R8A8_UNORM` / `B8G8R8X8_UNORM` (format 1).
     - `VIRTIO_GPU_CMD_RESOURCE_ATTACH_BACKING` (0x0106): Binds guest physical memory pages to resource ID.
     - `VIRTIO_GPU_CMD_SET_SCANOUT` (0x0103): Connects resource ID to display scanout 0.
     - `VIRTIO_GPU_CMD_TRANSFER_TO_HOST_2D` (0x0105): Copies modified guest memory sub-rectangles to host GPU texture.
     - `VIRTIO_GPU_CMD_RESOURCE_FLUSH` (0x0104): Signals host GPU to flush resource rectangle to display.
3. **Compositor Engine Integration**:
   - Updates `CompositorEngine` to maintain double-buffered render pipeline.
   - Renders Nitpicker security borders with dirty rectangle registration.
   - Fallback hierarchy: VirtIO-GPU 2D -> BGA hardware fallback -> UEFI/VBE GOP linear framebuffer.
