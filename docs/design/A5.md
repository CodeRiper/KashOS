# Design Note: Task A5 — Measured Boot, Sealing, and Anti-Rollback

## Motivation & Context
A secure microkernel operating system must guarantee that:
1. Every executable stage of the platform boot sequence (firmware, hardware config, bootloader, kernel code, Secure Boot policy, initrd manifest) is cryptographically measured and recorded into an unforgeable TCG Event Log.
2. Sensitive credentials (such as disk encryption keys and root identity tokens) can be cryptographically sealed to specific composite PCR policies and fail closed if a single bit of the measured boot chain changes.
3. System firmware and microkernel images cannot be downgraded to older, vulnerable releases (Anti-Rollback Protection).

## Architecture

### 1. TCG PC Client Measured Boot Event Log
The TCG PC Client Platform Firmware Profile specification defines a structured binary log of events accompanying PCR extension.
Each log entry contains:
- `pcr_index: u32`: Targeted PCR register (0..9).
- `event_type: u32`: TCG event classification (e.g. `EV_S_CRTM_CONTENTS`, `EV_POST_CODE`, `EV_SEPARATOR`, `EV_ACTION`).
- `digest: [u8; 32]`: SHA-256 measurement digest.
- `event_data: [u8; 48]`: Human-readable identifier or tag (e.g., `"CRTM Firmware"`, `"Microkernel ELF"`, `"Secure Boot Policy"`).

### 2. Monotonic Anti-Rollback Engine
- Protects against malicious rollbacks to superseded kernel builds.
- Tracks `security_version` (epoch counter). For KashOS v0.2.0, the baseline epoch is `2`.
- Integrates with TPM 2.0 NV Counter (`TPM2_NV_DefineSpace`, `TPM2_NV_Increment`, `TPM2_NV_Read`).
- If an incoming payload presents `version < current_counter`, the bootloader and microkernel fail closed with `RollbackDetected`.

### 3. Fail-Closed Sealing & Cold-Boot Defense
- Keys sealed to composite PCR policies (PCR 4: Kernel Code, PCR 7: Secure Boot Policy).
- In the event of a PCR policy mismatch during unseal:
  - Return `TpmError::PolicyMismatch`.
  - Securely scrub output buffers with `volatile_set` and `clflush` CPU cache line invalidation.
  - Retain vault in locked state.

### 4. Interactive Shell Inspection
- Wire `tpm` command in `kernel/src/shell.rs` to allow operators to inspect:
  - `tpm pcr`: Current PCR digests (PCR 0..9).
  - `tpm log`: Recorded TCG Event Log entries.
  - `tpm rollback`: Current anti-rollback monotonic epoch counter.
