# Design Note: T-F03 — APIC Timer Calibration Against PIT & Hardware Fallback (V-13, V-14)

## Status
- **Author**: Akash <akash.official.j@gmail.com>
- **Date**: 2026-10-18
- **Area**: Timer & Interrupt Architecture, Local APIC, 8254 PIT, Real Hardware T0 Baseline
- **Build Guide Phase**: Stage B / Task F-03

## Problem Statement
In `kernel/src/arch/x86_64/apic.rs`, the Local APIC timer was hardcoded to `write32(APIC_TIMER_ICR, 625_000)` based on an assumption that the APIC bus clock runs at 1.0 GHz (true in QEMU's default model, but false on real Core 2 Duo, Pentium III/IV, AMD, or bare metal machines).
On real vintage T0 hardware, the APIC timer bus clock depends on the Front Side Bus (FSB) frequency (e.g., 100 MHz, 133 MHz, 200 MHz, 333 MHz). Hardcoding 625,000 caused ticks to fire at incorrect rates (ranging from 10 Hz to 400 Hz instead of the target 100 Hz), distorting preemption time slices and clock accounting.
Furthermore, on systems where Local APIC is disabled or absent, the kernel masked legacy PIC without configuring a fallback timer.

## Implementation Approach
1. **Dynamic Calibration via 8254 PIT Channel 2**:
   - Configure Local APIC timer divide register to 16 (`APIC_TIMER_DCR = 0x3`).
   - Set APIC LVT Timer to One-Shot mode (`0x0001_0000 | TIMER_VECTOR`) and load Initial Count Register (`APIC_TIMER_ICR`) with `0xFFFF_FFFF`.
   - Program 8254 PIT Channel 2 for a precise 10 ms countdown (11,932 PIT cycles at 1,193,182 Hz).
   - Poll PIT Channel 2 output pin (port `0x61` bit 5) until the 10 ms interval elapses.
   - Read APIC Current Count Register (`APIC_TIMER_CCR`).
   - The elapsed ticks in 10 ms: `ticks_10ms = 0xFFFF_FFFF - ccr`.
   - For 100 Hz periodic interrupts (10 ms period), `calibrated_icr = ticks_10ms`.
   - Store APIC bus frequency in MHz: `(ticks_10ms * 16 * 100) / 1_000_000`.
2. **Periodic Activation**:
   - Switch APIC LVT Timer to Periodic mode (`TIMER_PERIODIC | TIMER_VECTOR`) with unmasked delivery.
   - Load `APIC_TIMER_ICR` with `calibrated_icr`.
3. **Fallback to Legacy 8254 PIT**:
   - If Local APIC is unavailable or calibration yields invalid ticks (< 100), configure 8254 PIT Channel 0 in Mode 2 (rate generator) at 100 Hz (divisor 11,932) and unmask IRQ0 on legacy 8259 PIC.
4. **Invariant TSC Detection**:
   - Query CPUID leaf `0x80000007` (EDX bit 8) for Invariant TSC (TSC ticks at constant rate across P/C/T-states).
