## 1. Objectives
1. Implement real multi-core CPU bring-up (INIT-SIPI-SIPI sequence) for Application Processors (APs) discovered via ACPI MADT.
2. Provide a 16-bit to 64-bit trampoline page (`0x8000`, page frame `0x08`) that transitions APs from real mode to long mode with the kernel PML4 CR3 and per-core stack.
3. Initialize Local APIC for secondary cores (`apic::init_ap()`), setting SVR, TPR, and per-core timer.
4. Support multi-core work distribution in `kscheduler` and Inter-Processor Interrupts (IPIs) for TLB shootdown and cross-core synchronization.
5. Adhere to Rule R19: support single-core profile T0 (gracefully skip non-existent APs) as well as multi-core profile T1 (4 cores).

## 2. AP Bring-up Architecture (Intel SDM Vol 3A)
```
  BSP (Bootstrap Processor)                  AP (Application Processor)
  ─────────────────────────                  ──────────────────────────
  1. Parse ACPI MADT (Find APIC IDs)
  2. Setup Trampoline at 0x8000
  3. Send INIT IPI -> ICR
  4. Delay 10 ms
  5. Send SIPI (vector 0x08) -> ICR
  6. Delay 200 us
  7. Send 2nd SIPI (vector 0x08)
  8. Wait for AP handshake                  ──> Starts in 16-bit Real Mode @ 0x8000
                                                Load GDT, Enter 32-bit PM (CR0.PE=1)
                                                Enable PAE (CR4.PAE=1), Long Mode (EFER.LME=1)
                                                Load Kernel CR3, Enable Paging (CR0.PG=1)
                                                Jump to 64-bit Long Mode
                                                Setup RSP -> per-core stack
                                                Initialize Local APIC
                                                Set PER_CPU[i].online = true
  9. Confirm AP online (or timeout T0)
```

## 3. Scheduler SMP Enhancement
- Extend `kscheduler` with multi-core safe work scheduling and per-CPU state.
- Ensure APIC timer ticks on each core trigger `plan_context_switch` without lock contention or lost tasks.
