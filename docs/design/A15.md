## 1. Objectives & Specification
1. **Hardened AHCI SATA Controller Driver (`kblock/src/ahci.rs`)**:
   - Complete Physical Region Descriptor Table (PRDT) layout within AHCI command tables (offset 0x80 following CFIS and ACMD).
   - Populate `prdtl = 1`, `dba` (data physical address), and `dbc` (transfer byte count with interrupt bit) for `READ DMA EXT` (0x25) and `WRITE DMA EXT` (0x35).
   - Implement real `flush_cache` issuing `ATA_CMD_FLUSH_EXT` (0xEA) with completion polling on `port.ci`.
   - Implement port status and error validation (`port.tfd`, `port.serr`, `port.is`).
2. **NVMe PCIe Controller Driver (`kblock/src/nvme.rs`)**:
   - Define NVMe 1.4 register offsets and bitmasks: `CAP`, `VS`, `CC`, `CSTS`, `AQA`, `ASQ`, `ACQ`, and dynamic doorbell registers based on `CAP.DSTRD`.
   - Implement circular queue management: `NvmeQueue` with Submission Queue (64-byte SQE) and Completion Queue (16-byte CQE) tracking phase tags and doorbell updates.
   - Implement Controller Initialization sequence:
     1. Read capabilities (`CAP`), disable controller (`CC.EN = 0`), wait for `CSTS.RDY == 0`.
     2. Initialize Admin Submission & Completion Queues (ASQ / ACQ), configure `AQA`.
     3. Enable controller (`CC.EN = 1`, `IOSQES = 6`, `IOCQES = 4`), poll `CSTS.RDY == 1`.
     4. Admin commands: `Identify` (Namespace 1) to determine sector count and LBA format.
     5. Admin commands: `Create I/O CQ` (0x05) and `Create I/O SQ` (0x01).
   - Implement `PersistentBlockDriver` for `NvmeController`:
     - `read_sectors`: Issues NVM Read (0x02) with LBA and PRP1, rings doorbell, awaits CQE phase inversion.
     - `write_sectors`: Issues NVM Write (0x01) with LBA and PRP1, rings doorbell, awaits CQE phase inversion.
     - `flush_cache`: Issues NVM Flush (0x00), rings doorbell, awaits CQE.
3. **PCI Detection & Kernel Integration**:
   - Add `find_nvme()` to `kernel/src/arch/x86_64/pci.rs` (class 0x01, subclass 0x08).
   - Update `kernel/src/blockdev.rs` probe order: NVMe -> AHCI -> VirtIO-Block -> Legacy PATA/IDE -> Volatile RAM.
   - Update driver status in `kash.rs` to reflect active NVMe / SATA controller.
