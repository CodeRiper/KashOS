# Design Note: Task A6 — Real TCP/IP Stack with smoltcp

## Current audit state (2026-10-20)

**Status: Needs revalidation.** `knet` contains a smoltcp device and socket
model, but its in-memory rings are not connected to the physical NIC. The
kernel service previously instantiated that model without polling it and also
kept a separate static-address socket model. It now disables TCP/DHCP/ingress,
rejects all egress, and keeps the gateway state private. These changes avoid
presenting package-level model tests as end-to-end network support.

Before A6 can be considered implemented, connect the real NIC RX/TX queues to
smoltcp, run the packet filter on both directions, add DHCP/DNS behavior, and
verify it with packet-level QEMU tests. A live tunnel and killswitch policy
must be validated separately; a boolean gateway state is not evidence of an
anonymity route.

## Motivation & Context
A secure, capability-based microkernel workstation must provide authentic network transport without reliance on hardcoded static host tables or synthetic loopback shortcuts:
1. Standard RFC 793 TCP 3-way handshake (SYN -> SYN-ACK -> ACK) with real state tracking.
2. Automated IP address acquisition via DHCPv4 and dynamic DNS name resolution.
3. Native packet filtering (`knet::FilterTable`) and fail-closed killswitch mediation on both ingress and egress frames before they touch the wire or stack.
4. Clean hardware integration with physical NICs (Intel e1000 / VirtIO-net) and loopback IPC transport.

## Architecture

### 1. smoltcp 0.14 Integration & Device Driver Adapter
- `smoltcp = { version = "0.14", default-features = false, features = ["alloc", "proto-ipv4", "proto-dhcpv4", "proto-dns", "socket-tcp", "socket-udp", "socket-icmp", "socket-dhcpv4", "socket-dns", "medium-ethernet"] }`
- Implement `smoltcp::phy::Device` for `RingDevice`:
  - `receive()` retrieves frames from the NIC RX SPSC ring and wraps them in `RxToken`.
  - `transmit()` provides `TxToken` writing outgoing frames to the NIC TX descriptor ring.
  - Device capabilities specify Ethernet medium and 1500-byte MTU.

### 2. Network Interface & Socket Set
- `smoltcp::iface::Interface` configured with current MAC address (derived from hardware CSPRNG with locally-administered unicast bit set).
- Managed `SocketSet` holding:
  - DHCPv4 client socket for dynamic IP address leasing and default gateway discovery.
  - DNS client socket querying designated upstream resolvers without static host tables.
  - TCP client/listener sockets with standard send/receive ring buffers (4 KiB each).
  - ICMP sockets for real ping echo requests and round-trip verification.

### 3. Fail-Closed Killswitch & Packet Filter Pipeline
- Ingress (`RX`): Raw Ethernet frame -> `FilterTable::evaluate()` -> if Allowed, handed to `smoltcp::iface::Interface::poll()`.
- Egress (`TX`): `smoltcp` generated frame -> `FilterTable::evaluate()` -> if Allowed and Killswitch Inactive, dispatched to hardware NIC.
- If Anonymity Gateway / VPN tunnel drops, killswitch engages immediately, dropping 100% of egress frames.

### 4. Public API & Service Contract
- Expose authoritative APIs in `knet` / `kernel::net`:
  - `dhcp_status() -> Option<Ipv4Cidr>`
  - `tcp_connect(remote_ip: [u8; 4], remote_port: u16) -> Result<SocketHandle, NetError>`
  - `tcp_send(handle: SocketHandle, data: &[u8]) -> Result<usize, NetError>`
  - `tcp_recv(handle: SocketHandle, buf: &mut [u8]) -> Result<usize, NetError>`
  - `resolve(name: &str) -> Result<[u8; 4], NetError>`
  - `ping(ip: [u8; 4], seq: u16) -> Result<u64, NetError>`
