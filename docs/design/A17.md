## 1. Objectives & Specification
1. **FADT (Fixed ACPI Description Table) Parser (`kernel/src/arch/x86_64/acpi.rs`)**:
   - Locate FADT (`FACP`) table via RSDP -> XSDT/RSDT.
   - Parse hardware register locations:
     - DSDT physical pointer (32-bit offset 40, 64-bit `X_DSDT` offset 140).
     - `SMI_CMD` port (offset 48), `ACPI_ENABLE` byte (offset 52).
     - `PM1a_CNT_BLK` (offset 64), `PM1b_CNT_BLK` (offset 68).
     - `RESET_REG` Generic Address Structure (offset 116) and `RESET_VALUE` (offset 128).
     - Support flags (offset 112), including `RESET_REG_SUP` (bit 10).
2. **AML Bytecode Scanner for Sleep State 5 (`\_S5`)**:
   - Traverse the DSDT / SSDT AML bytecode to find the `_S5` definition block (`Name(_S5, Package() { slp_typa, slp_typb, ... })`).
   - Extract raw `SLP_TYPa` and `SLP_TYPb` sleep types.
3. **Deterministic Power Management Operations**:
   - **`acpi_poweroff()`**:
     - Enable ACPI mode if not already active via `SMI_CMD` with `ACPI_ENABLE`.
     - Write `(SLP_TYPa << 10) | (1 << 13)` to `PM1a_CNT_BLK`.
     - Write `(SLP_TYPb << 10) | (1 << 13)` to `PM1b_CNT_BLK`.
     - Fallback chain: QEMU/Bochs (port `0x604` / `0xB004`), VirtualBox (port `0x4004`), triple fault.
   - **`acpi_reboot()`**:
     - ACPI Reset Register (FADT `RESET_REG` write `RESET_VALUE`).
     - PCI Reset Control Register (port `0xCF9` write `0x02` then `0x06`).
     - PS/2 8042 Keyboard Controller reset pulse (command `0xFE` to port `0x64`).
     - Fast A20 Reset (port `0x92` bit 0).
     - Triple fault fallback.
4. **Shell & Kernel Architecture Integration**:
   - Provide `reboot()` in `crate::arch` alongside `shutdown()`.
   - Update `kernel/src/shell.rs` to call `crate::arch::reboot()` on `reboot`.
