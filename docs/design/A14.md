# Design Note: Task A14 — UEFI Boot, Secure Boot & Measuring Loader

## Metadata

## 1. Objectives & Specification
1. Implement PE32+ UEFI executable parser and Authenticode structure validation in `kboot`:
   - DOS header (`MZ`), PE signature (`PE\0\0`), COFF header (`IMAGE_FILE_MACHINE_AMD64`), Optional Header 64 (`PE32+` magic `0x020B`).
   - Authenticode Data Directory (Directory Index 4: `IMAGE_DIRECTORY_ENTRY_SECURITY`).
   - `WinCertificate` structure parsing (`WIN_CERT_TYPE_PKCS_SIGNED_DATA`, `WIN_CERT_TYPE_EFI_GUID`).
   - Authenticode SHA-256 digest computation according to Microsoft PE/COFF Authenticode specification (excluding checksum and security directory).
2. Implement Secure Boot policy verification:
   - Check `SecureBootState` (Enabled, Disabled, SetupMode, DeployedMode).
   - Enforce signature & certificate validation when Secure Boot is Enabled.
3. Implement TCG PC Client Measuring Loader:
   - Measures candidate kernel image into TPM PCR 4 (`PCR_KERNEL_CODE`).
   - Computes SHA-256 hash and appends `TcgEventLogEntry` with event type `EV_IPL` / `EV_COMPACT_HASH`.
   - Simulates monotonic hash extension: `PCR_new = SHA256(PCR_old || measurement)`.
   - Anti-rollback verification: rejects candidate images with epoch < `KASH_SECURITY_EPOCH`.
4. Unified `KashBootInfo` handoff:
   - Sets `magic = KASH_BOOT_MAGIC`.
   - Sets `boot_source = BootSource::Uefi`.
   - Encapsulates GOP Framebuffer, ACPI RSDP, memory map, and attested kernel measurement hash.
5. Update `kernel/src/arch/x86_64/mod.rs` & `status.rs`:
   - Detects `boot_info.boot_source == BootSource::Uefi` and updates `status.uefi_boot = ComponentStatus::Real`.
   - If booted via BIOS/PVH, sets `status.bios_pvh_boot = ComponentStatus::Real` and `status.uefi_boot = ComponentStatus::NotAvailable`.
