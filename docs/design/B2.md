# B2: CNode Guarded Radix Trees & Capability Derivation Tree (CDT)

## Overview

Milestone B2 implements the seL4 CSpace address resolution mechanism: guarded
radix trees that translate capability pointers (CPtrs) into slot indices through
multi-level CNode traversal. It also completes the full set of seL4 CNode
invocations on the `SeL4CapabilityCore` and hardens the Capability Derivation
Tree (CDT) with sibling-linked integrity invariants.

## seL4 CSpace Resolution Algorithm (Reference Manual §3.2)

A capability pointer (CPtr) is a variable-length bit string consumed left-to-right:

```
CPtr = [ guard_bits | radix_bits | remaining_bits... ]
```

At each CNode level:
1. **Guard check** — extract `guard_size` bits from the CPtr. If they do not
   match the CNode's stored `guard` value, resolution fails with `GuardMismatch`.
2. **Radix index** — extract the next `radix` bits to compute a slot index
   within the CNode (0..2^radix - 1).
3. **Depth consumed** — `guard_size + radix` bits are consumed at each level.
4. **Terminal** — if remaining depth reaches 0, the slot is the final result.
   Otherwise, the slot must contain another CNode and resolution continues.

## CNode Operations (seL4 Reference Manual §3.3)

| Syscall | Purpose |
|---|---|
| `CNode_Copy` | Copy cap from src to dst with rights mask |
| `CNode_Move` | Move cap (src emptied), children re-parented |
| `CNode_Mutate` | Move + attenuate rights atomically |
| `CNode_Rotate` | 3-way atomic rotation: src→pivot, pivot→dst |
| `CNode_SaveCaller` | Save caller's Reply cap into a slot |
| `CNode_Delete` | Remove a cap, re-parent children to grandparent |

## CDT Invariants (verified at runtime)

- I1: No cap has more rights than its parent (monotonic attenuation).
- I2: No slot is simultaneously parent and child of itself (acyclicity).
- I3: Sibling links are consistent (prev↔next bijection).
- I4: Every child's parent pointer is consistent with the parent's child list.
- I5: Null slots have no CDT links.

## Implementation Notes

- Guard is stored as `(guard: u64, guard_size: u8)` in `CapKind::CNode`.
- Maximum CSpace depth is 64 bits (sum of all guard_size + radix values).
- Resolution loop caps at 64 bits consumed to prevent infinite loops.
- All CNode ops are atomic: they either fully succeed or leave state unchanged.
