# Design Note: Task A8 — TLS 1.3 & HTTPS Client Architecture

## Context & Objectives
In Task A6, KashOS integrated `smoltcp` 0.14 for native `#![no_std]` TCP/IP networking, and in Task A7 multi-NIC hardware drivers (e1000, VirtIO-Net, RTL8139) were made real.
Task A8 addresses Finding F12 / Task A8:
- Prior state: `kernel/src/net.rs` returned `Err(NetError::NotAvailable)` for `http_get`, and `kernel/src/browser.rs` displayed canned pages with no HTTPS or live web capability.
- Objective: Implement real TLS 1.3 client record framing, Server Name Indication (SNI) routing, and HTTPS request/response processing compliant with RFC 8446 in `#![no_std]`.

## Protocol & Architectural Design

### 1. TLS 1.3 Record Layer (`knet::tls`)
- **TLS Record Format**:
  - `ContentType`: `Handshake (22)`, `ApplicationData (23)`, `Alert (21)`, `ChangeCipherSpec (20)`.
  - `LegacyRecordVersion`: `0x0303` (TLS 1.2 legacy wire compatibility per RFC 8446 Section 5.1).
  - `Length`: 16-bit big-endian payload byte count.
- **ClientHello Construction**:
  - `ClientRandom`: 32 cryptographically secure random bytes.
  - `CipherSuites`: `TLS_CHACHA20_POLY1305_SHA256` (`0x1303`) and `TLS_AES_128_GCM_SHA256` (`0x1301`).
  - `Extensions`:
    - `server_name` (`0x0000`): Domain name for SNI routing.
    - `supported_versions` (`0x002B`): Declares TLS 1.3 (`0x0304`).
    - `supported_groups` (`0x000A`): Named curve X25519 (`0x001D`).
    - `key_share` (`0x0033`): Client ephemeral public key share.
    - `signature_algorithms` (`0x000D`): Ed25519, RSA-PSS-SHA256, ECDSA-P256.

### 2. HTTP/1.1 Client Framing
- **Request Generation**:
  - Method: `GET`
  - Headers: `Host: <domain>`, `User-Agent: KashOS-Browser/0.2.0 (ELinks; Microkernel)`, `Accept: text/html,application/xhtml+xml`, `Connection: close`.
- **Response Parsing**:
  - Status line decoding (`HTTP/1.1 200 OK`, `301 Moved`, `404 Not Found`).
  - Header stripping, content extraction, and chunked transfer decoding.

### 3. Integration with Kernel Network Service & ELinks Browser
- `NetworkService::http_get(url)`:
  - Dissects URL into protocol (`http` vs `https`), host, port, and path.
  - Enforces fail-closed kill switch (`GatewayStatus::Down` -> `NetError::KillSwitchBlocked`).
  - Enforces default-deny packet filtering (blacklisted tracking domains -> `NetError::PacketFiltered`).
  - Dispatches through smoltcp TCP sockets and TLS 1.3 record layer.
- `ElinksBrowser`:
  - Renders live pages fetched over the network.
  - Updates navigation and status banners to reflect live HTTPS client capabilities.
