## 1. Objectives & Specification
1. Implement standard disk partition discovery (MBR and GPT) in `kernel/src/blockdev.rs`.
2. Define the authoritative KashOS disk layout:
   - **Partition 1 (ESP)**: FAT32 EFI System Partition (`0xEF` MBR / `C12A7328-F81F-11D2-BA4B-00A0C93EC93B` GPT).
   - **Partition 2 (Boot)**: Read-only measured kernel boot partition (`0x83` / `0BC08366-D574-45F1-9624-E4476D3046B7`).
   - **Partition 3 (kvault Root Pool)**: Authenticated persistent root volume (`0x83` / `8347E30D-294B-4B2A-89A5-7A4CB2F5E5A2`).
3. Bind `KBlockDeviceAdapter` dynamically to the discovered partition's LBA boundaries (`start_lba`, `block_count`), preventing cross-partition overwrite.
4. If no partition table exists (raw test disk image), gracefully fall back to whole-disk mode.
5. Provide comprehensive unit tests for partition parsing and boundary enforcement.
